# XBR-Script

In the process of upscaling Minecraft textures using the XBR or XBRZ algorithm, there are a number of intermediate processing steps which are sometimes necessary. Due to the tedium of performing these steps manually, and my personal grief at the undocumented nature of these procedures, I have found it necessary to implement a scripting interface by which these image manipulation procedures may be documented and performed mechanically.

I am implementing this in Java 26, and quite exclusively for Windows at this point in time.
